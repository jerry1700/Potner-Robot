# potner_firmware — ESP32 저수준 컨트롤러

젯슨이 못 하는 실시간 작업만 담당합니다.

| 담당 | 이유 |
|---|---|
| 엔코더 쿼드러처 디코딩 | 초당 약 2,930카운트 × 2. 리눅스 파이썬으로는 카운트를 흘립니다 |
| 바퀴 속도 PID (100Hz) | 주기가 흔들리면 안 되는 제어 루프 |
| 20kHz PWM 생성 | 가청 대역 밖이라 조용합니다 |
| 워치독 정지 | 젯슨이 죽어도 로봇이 계속 달리지 않게 |

## 배선

### ESP32 → BTS7960 (모터 드라이버 2개)

| ESP32 핀 | 연결 |
|---|---|
| GPIO 25 | 좌 BTS7960 RPWM |
| GPIO 26 | 좌 BTS7960 LPWM |
| GPIO 32 | 우 BTS7960 RPWM |
| GPIO 33 | 우 BTS7960 LPWM |
| 3.3V | 양쪽 BTS7960 의 R_EN, L_EN (항상 활성) |

### 엔코더 → ESP32 (3.3V 직결, 레벨 시프터 불필요 — 실측 확인)

FIT0403 엔코더는 **VCC를 3.3V로 넣어도 정상 동작**합니다. 실기에서 손으로
축을 돌려 A/B 출력이 0~3.3V로 잘 스위칭되는 것과, PWM 구동 중 틱 카운트가
정상적으로 올라가는 것까지 확인했습니다. 레벨 시프터나 저항 분압 없이
직결하면 됩니다.

| ESP32 핀 | 연결 |
|---|---|
| GPIO 34 | 좌 엔코더 A (직결) |
| GPIO 35 | 좌 엔코더 B (직결) |
| GPIO 36 | 우 엔코더 A (직결) |
| GPIO 39 | 우 엔코더 B (직결) |

엔코더 VCC/GND도 ESP32 3.3V/GND에 연결합니다.

GPIO 34~39를 고른 이유는 **입력 전용 핀**이라서입니다. 출력으로는 못 쓰는
핀이니 엔코더에 배정하면 출력 가능한 핀을 아낄 수 있습니다.

### 절대 쓰면 안 되는 핀

- **GPIO 0, 2, 12, 15** — 부팅 스트래핑 핀. 여기에 뭘 물리면 ESP32가 안 켜집니다
- **GPIO 6~11** — 내부 플래시 전용

### ⚠️ 전원 접지

3S(모터)와 4S(젯슨) 배터리를 따로 쓰므로 **GND 한 가닥을 반드시 서로
연결**해야 합니다. ESP32는 젯슨 USB에서 전기를 받고 BTS7960은 3S에서
받는데, 기준점이 다르면 PWM 신호를 못 알아듣습니다. 플러스는 절대 섞지
마세요.

여기서 "GND"는 BMS에 그렇게 라벨링된 별도 핀이 아니라, **3S 팩의 (−)
방전 리드선**을 가리킵니다. 이 리드선을 BTS7960 `B−`와 4S 팩 (−) 양쪽으로
분기해서 연결하면 됩니다.

## 시리얼 프로토콜

`src/potner_base/potner_base/serial_protocol.py` 와 **반드시 일치**해야
합니다. 한쪽만 고치면 조용히 오작동합니다.

```
젯슨 -> ESP32
    V,<좌 m/s>,<우 m/s>*<체크섬>\n
    S*<체크섬>\n

ESP32 -> 젯슨
    O,<좌틱>,<우틱>,<좌범퍼mm>,<우범퍼mm>,<millis>*<체크섬>\n
```

체크섬은 `*` 앞까지 모든 문자의 XOR을 2자리 16진수로 적습니다.

## 튜닝이 필요한 값

`src/main.cpp` 상단에 모여 있습니다.

- `WHEEL_DIAMETER_M` — 조립 후 실측
- `KP`, `KI`, `KD` — 바퀴가 떨리면 KP를 낮추고, 목표 속도에 못 미치면 KI를 올립니다
- `MAX_WHEEL_MPS` — 안전 상한

`COUNTS_PER_REV = 1440` 은 FIT0403 사양에서 나온 확정값이니 건드리지 마세요.

## 첫 동작 확인 순서

**바퀴를 공중에 띄운 채로** 시작하세요. 바닥에 놓고 하면 책상에서 떨어집니다.

1. `pio run --target upload` 로 업로드
2. `pio device monitor` 로 `O,...` 프레임이 30Hz로 올라오는지 확인
3. 손으로 바퀴를 굴려서 틱 카운트가 변하는지 확인 — 안 변하면 배선 문제
4. 왼쪽 바퀴를 앞으로 굴렸을 때 카운트가 **증가**하는지 확인. 감소하면
   엔코더 A/B를 서로 바꾸세요
5. 시리얼 모니터에 `V,0.05,0.05*` + 체크섬을 직접 입력해 바퀴가 도는지 확인
