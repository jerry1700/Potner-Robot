사용자가 (폰 음성 또는 모니터 타이핑으로) LLM과 대화할 때, 현재 코드
기준으로 무엇을 답할 수 있고 무엇을 못 하는지 정리한다. 근거는 전부
`src/potner_llm/`과 `voice-chat-server/`의 실제 구현이다 (2026-08-03).
질문 예시 중심의 사용자 관점 정리는
[`LLM_QUESTION_EXAMPLES.md`](LLM_QUESTION_EXAMPLES.md) 참고.

## 답할 수 있는 것

### 1. 센서 상태 질문 — "지금 온도 어때?", "습도는?", "물 줘야 해?"

LLM이 툴을 불러 실데이터로 답한다. 판정 라벨과 수치를 함께 쓴다.

| 툴 | 내용 |
|---|---|
| `get_plant_status` | 4종 센서 요약 + 주의필요 여부 ("토양이 건조해서 물이 필요해요" 등) |
| `get_sensor_data` | 원시 측정값 + 판정 (토양수분%·온도°C·습도%·조도lux·CO2ppm) |
| `get_recent_events` | 최근 이벤트 로그 (아래 '못 하는 것' 참고) |

판정 기준(스킨답서스 보수 범위, `sensor_provider.py`):
토양 30~70% / 온도 15~30°C / 습도 30~70% / 조도 100~20000lux.
범위 밖이면 저온·고온·건조·과습 같은 라벨로, 값이 없으면 "미측정"으로
정직하게 답한다.

**⚠️ 데이터 현황**: 값의 출처는 아직 개발용 더미(`src/potner_llm/data/
sensors.json`)다. 라즈베리 실측 온습도로 바꾸는 배관(`SpringSensorSource`)은
완성돼 있고, 서버에 장치용 조회 경로가 열리면 config 5줄로 전환한다
([`LLM_SENSOR_INTEGRATION_PLAN.md`](LLM_SENSOR_INTEGRATION_PLAN.md)).
전환 전까지는 더미값 또는 "미측정"으로 답한다.

### 2. 식물 프로필 — "네 이름이 뭐야?", "무슨 식물이야?"

이름(초록이)·종(스킨답서스)·성장 단계(성장기)·말투가 프로필로 주입된다.
마지막 급수 시각은 기록이 있으면 답한다 (`PlantProfile.last_watered_at`).

### 3. 맥락 있는 대화 — "아까 내가 뭐라고 했지?"

세션별 히스토리가 유지되고, 대화 종료 시 저장 → 다음 접속에서 복원된다
(`conversation.backend: file`). 폰 음성과 모니터 타이핑이 같은
session_id를 쓰면 하나의 대화로 이어진다.

### 4. 정형 발화 — 코드가 직접 부르는 것들

`DialogueService`에 대화 외 진입점이 있다: `brief()`(짧은 상태 인사),
`report()`(상태 보고), `diary()`(하루 일기 생성 — 페르소나 말투 반영).

### 5. 일반 지식·잡담

"식물한테 커피 줘도 돼?" 같은 일반 지식은 LLM 자체 지식으로 답한다.
단 **자기 센서에 대한 수치·상태 주장은 factcheck가 검증**한다:
- 데이터에 없는 수치를 말하면(날조) 차단 → 재생성 → 그래도 실패 시
  검증된 값만으로 만든 근거 기반 응답으로 폴백
- 급수 기록이 없는데 "아까 물 줬잖아"라고 하면 차단
- 토양이 말랐는데 "촉촉해"라고 하면 차단

## 못 하는 것 (물어봐도 정직한 한계 답변이 나감)

| 질문 | 왜 |
|---|---|
| 실시간 실측 온습도 | 서버 장치용 조회 경로 대기 중 — 그 전까지 더미/미측정 |
| CO2, 사진 기반 상태 | 값이 항상 None (센서·연동 없음) |
| "물 줘" / "이리 와" (동작 명령) | 액추에이터 권한이 없다 — 급수·이동은 서버가 명령한다 |
| "최근에 무슨 일 있었어?" | `get_recent_events`는 있지만 **이벤트를 기록하는 주체가 아직 없어** 사실상 빈 목록이다 |
| 다른 식물/기기 정보 | 자기 프로필·센서만 안다 |

## 음성 경로에서의 추가 사항

폰 녹음 → GMS whisper-1 STT → 위 대화 → GMS TTS → 폰 또는 로봇 스피커
(`AUDIO_SINK`). 질문은 300자까지 받는다. LLM 첫 토큰 전에 필러
("음, 잠깐만 생각해볼게요!")가 먼저 재생된다 — 이건 LLM 답변이 아니라
지연 가림용 고정 음성이다.
