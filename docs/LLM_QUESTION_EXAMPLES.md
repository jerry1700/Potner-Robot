# LLM 대화 질문 카탈로그 — 무엇을 물어볼 수 있나

사용자(시연·데모 포함) 관점에서 "이런 질문을 하면 답이 나온다/안 나온다"를
예시 중심으로 정리한다. 구현 근거 중심의 정리는
[`LLM_CAPABILITIES.md`](LLM_CAPABILITIES.md) 참고. 근거는 전부
`src/potner_llm/`(prompt_builder·tools·factcheck·validator)의 실제 코드다
(2026-08-04, potner 백엔드 기준).

## 답할 수 있는 질문

### 1. 현재 상태 — 센서 (툴 호출로 실데이터 응답)

- "지금 온도 어때?" / "몇 도야?"
- "습도는 괜찮아?" / "습도 몇 퍼센트야?"
- "흙 안 말랐어?" / "물 줘야 해?" / "목말라?"
- "빛은 충분해?" / "너무 어둡지 않아?"
- "지금 상태 어때?" / "어디 불편한 데 없어?" (4종 요약 + 주의 문구)

값이 없으면 "미측정"으로 정직하게 답한다. 실측이 영하일 때
"영하 5도야" 같은 답도 정상 통과한다 (2026-08-04 factcheck 부호 처리).

### 2. 식물 프로필 — 자기소개

- "네 이름이 뭐야?" (초록이)
- "무슨 식물이야?" / "어떤 종이야?" (스킨답서스)
- "지금 얼마나 컸어?" (성장 단계: 성장기)
- "마지막으로 물 언제 받았어?" (`last_watered_at` 기록이 있을 때만 —
  기록이 없으면 모른다고 답한다)

### 3. 식물 돌보기 일반 지식 — LLM 자체 지식

- "스킨답서스는 물을 얼마나 자주 줘야 해?"
- "잎이 노랗게 변하면 왜 그런 거야?"
- "너한테 커피 줘도 돼?" / "사이다 주면 어때?"
- "분갈이는 언제 하는 게 좋아?"
- "겨울에는 어떻게 관리해 줄까?"

단, 답 속에서 **자기 센서에 대한 수치·상태 주장**을 하면 factcheck가
실측과 대조한다 — 날조 수치·가짜 급수 회상·상태 정반대 표현은 재생성
후 실패 시 근거 기반 폴백으로 대체된다.

### 4. 감정·잡담 — 페르소나 (다정하고 명랑한 반말)

- "안녕!" / "잘 잤어?" / "심심했어?"
- "오늘 기분 어때?"
- "너는 뭘 제일 좋아해?"
- "사랑해" / "고마워" 류의 감정 표현

형식 제약: 3문장 / 120자 이내, 한국어만, 이모지·마크다운은 후처리에서
제거된다(TTS 친화).

### 5. 지난 대화 맥락

- "아까 내가 뭐라고 했지?"
- "내 이름 기억해?" (알려준 적 있으면)
- 대화 종료 후 다시 접속해도 같은 session_id면 이어서 기억한다
  (`conversation.backend: file`). 폰 음성과 모니터 타이핑도 같은
  session_id면 하나의 대화다.

### 6. 정형 발화 — 질문이 아니라 코드가 부르는 진입점

`brief()`(상태 인사) / `report()`(외출 후 보고) / `diary()`(1인칭 일기).
음성 대화 흐름이 아니라 미션·스케줄 쪽에서 쓴다.

## 답하지 못하는 질문 (정직한 한계 답변·회피가 나감)

| 질문 예시 | 왜 못 하나 | 차단 위치 |
|---|---|---|
| "대통령 선거 누가 이길 것 같아?", "주식/코인 얼마나 올라?" | 실시간 정보 없음 + "센서 상태와 프로필의 사실만 근거로" 규칙 → 모른다고 하거나 식물 화제로 돌린다 | 프롬프트 (코드 차단 아님) |
| "오늘 뉴스 알려줘", "내일 날씨 어때?" | 외부 실시간 정보에 접근할 수 없다 | 프롬프트 |
| "물 줘", "이리 와", "사진 찍어" | 액추에이터 권한이 없다 — 급수·이동은 서버가 명령한다 | 구조 (툴 자체가 없음) |
| "최근에 무슨 일 있었어?" | `get_recent_events` 툴은 있으나 이벤트를 기록하는 주체가 아직 없어 빈 목록 | 데이터 부재 |
| "CO2 농도는?", "네 사진 보여줘" | 값이 항상 None (센서·연동 없음) | 데이터 부재 |
| "옆집 식물은 어때?", "다른 로봇 상태는?" | 자기 프로필·센서만 안다 | 구조 |
| "아프면 무슨 약 먹어야 해?" (사람 의료), "농약 마셔도 돼?" | 안전·의료 조언 금지 + 위험 조언 금칙어 | 프롬프트 + validator |
| 욕설이 섞인 응답 유도 | 금칙어 목록 검사 → 폴백 | validator |

주의: 정치·경제류는 **코드 수준의 차단 목록이 있는 게 아니라** 시스템
프롬프트("센서 상태와 프로필에 있는 사실만 근거로", "모르는 것은
모른다고")가 회피를 유도하는 방식이다. 모델이 일반 상식 수준에서 짧게
답해버릴 가능성은 남아 있다 — 확실한 차단이 필요해지면 validator에
주제 필터를 추가해야 한다.

## 입력 자체가 거부되는 경우 (LLM까지 가지 않음)

- 빈 질문 / 공백만: "질문이 비어 있어요…"
- 300자 초과: "질문이 너무 길어요…"
- 한글·영문 외 문자(키릴, 아랍 문자 등): "읽을 수 없는 글자가…"
- 특수문자만: "무슨 뜻인지 잘 모르겠어요…"

## 오류 시 안내 문구 (참고)

LLM 호출이 실패해도 무응답은 없다 — timeout("생각이 너무 길어졌어요…"),
rate limit("지금 질문이 몰려서 바빠요…"), 네트워크("바깥세상과 연결이
잠깐 끊겼어요…"), 그 외("지금은 대답하기 어려워요.")로 폴백한다.
